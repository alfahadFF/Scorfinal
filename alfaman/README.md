# ALFAMAN — صفحة إدارة منتجات SCOR (HTML واحدة)

- `alfaman.html` — صفحة الإدارة الكاملة (عربي): بلا حسابات ولا تسجيل دخول — الرابط السرّي هو الحماية،
  وبمجرد فتحها تعمل: جلب/تعديل/إدخال منتجات وفئات،
  صور سلايدر + صور إضافية، مواصفات ديناميكية، PDF، ونشر.
- `api.php` — ملف جسر واحد يصل الصفحة بقاعدة البيانات وينشر الصفحات الثابتة EN+AR.
- `install-pgsql.sql` / `install.sql` — إنشاء الجداول والسياسات (PostgreSQL / MySQL).
- `scor-products.xlsx` — بيانات الـ33 موديلًا الحالية بصيغة Excel للاستيراد من الصفحة.
- `templates/` — قوالب صفحات الموقع المستخدمة عند النشر.

## الإدخال بطريقتين
1. **مباشر**: من نموذج المنتج في الصفحة (مع رفع صور تُضغط تلقائيًا لأي حجم).
2. **Excel**: عدّل ملفًا بأربع أوراق (Categories / Products / Specs / Media) وارفعه من تبويب Excel.

## التشغيل
- محليًا: `php -S localhost:8002 -t alfaman` وافتح `alfaman.html` — تعمل فورًا بلا أي خطوة دخول.
- إنتاجيًا: انسخ `config.supabase.example.php` أو `config.onecom.example.php` إلى `config.php` واملأ بيانات القاعدة، ونفّذ ملف التثبيت المناسب داخل قاعدة فارغة.
